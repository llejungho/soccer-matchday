# MATCHDAY

축구 팀 관리 웹사이트의 첫 단계: 이메일 가입, 로그인, 로그아웃.

## 실행

Node.js 24 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:3000 을 엽니다. 회원가입은 이메일, 암호, 암호 재확인 세 항목으로 진행하고 완료하면 자동 로그인합니다. 암호는 8~128자입니다.

## 데이터와 계정

- `data/accounts.sqlite`에 계정을 영구 저장합니다. 이 파일을 지우면 계정이 삭제됩니다.
- 암호는 무작위 salt와 scrypt 해시로 보관합니다. 브라우저에는 HttpOnly 세션 쿠키만 저장합니다.
- 세션은 7일 후 만료합니다. 로그아웃 시 서버에서도 세션을 폐기합니다.
- 이메일 중복, 암호 불일치, 잘못된 로그인, 요청 횟수 제한을 서버에서 검사합니다.
- 현재 이메일 소유 확인 및 암호 재설정은 제공하지 않습니다.
- 계정마다 여러 팀을 만들고 팀명과 유니폼 색상을 변경하거나 선수를 추가할 수 있습니다.
- 선수를 추가하면 프로필 작성 화면을 열고, 기존 선수는 명단의 프로필 작성 / 수정 버튼으로 편집합니다. 선수 이름, 선호 포지션 최대 3개, 체력·적극성·공격력·수비력·전체 실력 평가를 저장합니다.
- 포지션은 CF, SS, LW, RW, AM, LM, CM, RM, DM, LWB, RWB, CB, GK 중 클릭 순서로 1·2·3순위를 정합니다. 다시 클릭하면 해제하고 남은 순위를 당깁니다.
- 평가는 각 항목 1~5점 정수 또는 미설정(null)입니다. 기존 선수와 새 선수의 기본값은 포지션 없음과 평가 미설정이며, 미설정은 0점이나 1점 평가와 구분됩니다. 향후 쿼터별 전술 구성에 사용할 수 있도록 항목별로 저장합니다.
- 감독 코멘트는 최대 2,000자로 저장합니다. 궁합은 본인을 제외한 같은 팀원 여러 명을 좋은 궁합 / 안 좋은 궁합으로 선택하며, 두 선수 사이의 관계로 저장되어 양쪽 프로필에 반영됩니다. 같은 선수 쌍에 좋은 궁합과 안 좋은 궁합을 동시에 지정할 수 없습니다.
- 스쿼드 메뉴에서 쿼터별 전술과 포메이션을 선택하여 자동 배치합니다. 코멘트의 개인플레이·팀플레이 조합과 좋은/안 좋은 궁합은 위치 개선에 활용하며 출전량 및 자리 수 때문에 모든 선호를 만족시키지 못할 수 있습니다.
- 팀 넘기기를 승인하면 감독별 판단인 코멘트와 궁합도 포지션·평가 점수와 함께 초기화됩니다. 기존 데이터베이스는 시작 시 코멘트 필드와 궁합 테이블을 추가하며 계정·팀·선수·기존 평가를 유지합니다.
- 팀이 하나이면 자동으로 선택합니다. 여러 팀이면 마지막으로 선택한 팀을 계정별로 기억합니다. 새 팀을 만들면 그 팀을 선택합니다.
- 팀 넘기기는 가입된 다른 이메일을 확인하여 요청합니다. 받는 사람이 로그인하면 모든 팀 메뉴 위에서 승인·거절할 수 있습니다. 요청 알림은 사이트 내부에서 표시하며 이메일을 발송하지 않습니다.
- 승인 전에는 기존 관리자가 계속 관리합니다. 승인하면 팀 소유권과 선수 이름·명단이 이전되지만 포지션과 모든 평가 점수는 미설정으로 초기화합니다. 초기화와 소유권 이전은 하나의 데이터베이스 트랜잭션으로 처리합니다. 기존 관리자는 해당 팀을 조회하거나 변경할 수 없습니다. 거절하거나 대기 중이면 기존 프로필을 유지합니다. 다른 팀의 프로필은 초기화하지 않습니다.
- 팀별 승인 대기 요청은 하나만 허용합니다. 팀 메뉴를 열거나 브라우저로 돌아오면 최신 요청과 관리 권한을 확인하며, 열린 화면은 5초마다 변경 사항을 확인합니다.

## 배포

현재 로컬 실행 버전입니다. 공개 운영 시 Node.js 24 서버, 영속 디스크, HTTPS가 필요합니다. `NODE_ENV=production`, `PUBLIC_ORIGIN=https://실제도메인`, `HOST=0.0.0.0`을 설정하세요. 포트는 `PORT`, 데이터 경로는 `DATA_DIR`로 지정할 수 있습니다. 다중 서버를 운영할 때에는 공용 데이터베이스와 분산 요청 제한으로 확장해야 합니다.

## 팀 전술과 추가 평가 항목

- 팀 전술 메뉴에서 전술명, 컨셉(선택), 우선 배치할 선수 성향(필수)을 추가·수정·삭제합니다. 전술은 현재 팀에 저장하며 쿼터별 선택과 자동 배치는 추후 연결합니다.
- 선수 평가 항목 하위 메뉴에서 감독이 항목을 등록·수정·삭제합니다. 새 항목은 팀당 최대 30개, 항목명 최대 30자이며 기본 5개 항목도 수정·삭제할 수 있습니다. 선수 프로필에서 각 항목을 1~5점 또는 미설정으로 저장합니다.
- 추가 항목을 삭제하면 해당 항목의 모든 선수 점수도 삭제됩니다. 팀 넘기기 승인 시 전술과 항목 이름은 유지하며 선수별 추가 점수는 초기화합니다.


## 화면과 시작 순서

- 첫 화면은 로그인이며, 회원가입과 비밀번호 찾기는 하단 메뉴입니다. 비밀번호 찾기는 이메일 발송 서비스 미연결로 지원 예정 안내를 표시합니다.
- 회원가입 후 팀 생성, 팀 생성 완료 후 팀 전술로 이동합니다. 다음 버튼으로 선수 관리에 들어가 평가 항목을 정한 뒤 선수를 등록합니다.
- 메뉴는 팀 생성 / 팀 전술 / 선수 관리 / 팀 선택 / 팀 이관입니다. 추가 평가 항목은 선수 관리에서 추가·수정·삭제하며 항목명 수정 시 기존 점수를 유지합니다. 팀명·유니폼 수정은 팀 생성 화면, 팀 넘기기와 받은 요청은 팀 이관 화면에 있습니다.
- 선수 번호는 1순위 포지션 기준으로 공격(CF, SS, LW, RW) 빨강, 미드필더(AM, LM, CM, RM, DM) 초록, 수비(LWB, RWB, CB) 파랑, GK 검정이며 미설정은 기존 색상입니다.


## 스쿼드 자동 구성

- 스쿼드 메뉴에서 이름, 1~12개 쿼터(기본 4개), 쿼터별 팀 전술 및 442/4231/433/343/352/4141 포메이션을 정합니다. 팀 선수 전체 선택·개별 선택과 이름·포지션만 입력하는 용병을 지원합니다.
- 선수별 지정 출전량은 0.5쿼터 단위이며 2, 2.5, 3, 4 등을 선택합니다. 공평 배분은 필드 10자리 × 쿼터 수와 GK 자리를 따로 최대한 균등하게 배분합니다. GK 체크 선수는 자동 구성에서 GK 자리에만 배치합니다.
- 반쿼터를 단위로 출전량과 동시 중복 금지를 먼저 맞추고 선호 포지션 1/2/3순위, 평가, 전술 키워드·추가 평가 항목명, 선수 궁합과 코멘트의 개인플레이/팀플레이 조합을 반영합니다. 전술 자연어 전체를 해석하는 외부 AI 서비스는 사용하지 않으며, 지역 개선을 적용하는 휴리스틱으로 모든 선호를 동시에 보장하지 않습니다.
- 인원·출전량이 부족하거나 요청 총량이 자리 수를 넘으면 빈자리·미충족 출전량을 경고하며 선택 출전량을 임의로 넘기지 않습니다. 선호 포지션 밖의 배치도 안내합니다.
- 결과에서 전·후반별 선수를 교체할 수 있습니다. 같은 전·후반의 선수를 선택하면 기존 자리와 서로 교환하여 중복 배치를 방지합니다. 최종 출전량과 쿼터별 출전표, 배치 설명 및 경기장 그림을 확인하고 저장합니다.
- 공유하기는 선수 이름·위치·포메이션·전술명만 담은 그림 스냅샷을 공개합니다. 평가·코멘트·궁합은 공개 응답에 포함하지 않습니다. 다시 공유하면 기존 링크는 종료되며 공유 종료도 지원합니다. PNG 저장은 배포 없이 전달할 수 있습니다. 로컬 링크를 다른 기기에서 사용하려면 공개 서버 배포가 필요합니다.
- 스쿼드도 계정별 팀 관리 권한을 검사합니다. 팀 이관 시 팀 선수의 저장된 평가 스냅샷도 초기화하며 이전 감독은 스쿼드 관리에 접근할 수 없습니다.


## 경기 기록과 포메이션 관리

스쿼드에서 팀별 포메이션을 추가·삭제합니다. 532, 541, 451 등 3~5개 줄의 필드 합계 10명 구성을 입력하면 자리를 생성합니다. 기존 그림과 기록은 삭제 뒤에도 유지됩니다. 쿼터별 승·무·패를 저장하면 포메이션·전술·선수 위치·조합별 승률과 표본 수를 볼 수 있습니다. 선수 통계는 0.5쿼터 단위이고 용병은 제외합니다. 결과 기록 시 당시 배치를 보존하며, 수정하려면 모든 결과를 미입력으로 되돌려야 합니다. 승률은 관측 통계이며 아직 자동 배치 점수에 반영하지 않습니다.

공개 운영 준비 파일은 Dockerfile, compose.yaml, Caddyfile, .env.example입니다. 도메인 연결·HTTPS·데이터 이전·백업 방법과 공개 운영 전 남은 작업은 [DEPLOYMENT.md](DEPLOYMENT.md)에 있습니다. Docker가 없는 현재 개발 PC에서는 컨테이너 배포 자체를 실행하지 않았습니다.

스쿼드 화면은 구성·팀 포메이션 관리·팀 스쿼드 분석 하위 메뉴로 나눴습니다. 출전량 단계에서 선수 포지션 순위를 표시하며 공평 배분에서는 쿼터 선택창을 숨깁니다. 1순위 GK는 자동 구분합니다. 선수별 지정 모드의 필드 출전량 상한은 10 × 쿼터 수이며, 초과 선택은 안내창과 함께 해당 선수의 남은 출전량으로 조정합니다. 서버에서도 같은 상한을 검증합니다.

선수 관리는 선수 목록·선수 추가·선수 평가 항목 하위 메뉴로 구성됩니다. 기본 5개 항목도 팀별로 이름을 수정하거나 삭제할 수 있습니다. 이름 수정은 기존 점수를 유지하며 삭제는 해당 팀 선수의 점수를 지웁니다. 삭제한 기본 항목은 재접속·서버 재시작 때 자동 복구되지 않습니다. 전부 삭제한 뒤 새로운 기준만 사용할 수도 있습니다. 스쿼드 평가는 현재 항목 이름과 전술 설명을 기준으로 점수를 참고합니다.
